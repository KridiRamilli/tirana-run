# Tirana Run design source of truth

These approved mockups are the visual source of truth for the Tirana Run PWA.

## Rules for agents and implementation
- Implement these screens pixel-perfect as closely as practical.
- Do not invent alternative layouts, colors, or navigation without explicit approval.
- Preserve the overall hierarchy, spacing, card style, typography feel, and green color system.
- The route is fixed in shape, but the user may start from the nearest point.
- Any illustrated map in a mockup is only a layout reference; the implemented product must use a real interactive map.
- The product is a PWA, not a native app.
- Audio content must support Albanian and English.
- Completion should support badge generation and social sharing.
- Profile is local-first; data can be stored locally first and synced later.
