# Itinerary screens

References:

- `design/mockups/approved/05-itinerary-map.png`
- `design/mockups/approved/06-itinerary-stops.png`

- Use a real interactive MapLibre map; the illustrated map is layout reference only.
- Render one fixed GeoJSON route, 13 numbered stops, start/finish treatment, route stats, details card, and persistent “Nis ecjen” action.
- The fixed geometry is not editable, but the user may join from the nearest suitable point.
- The stop-list view is an accessible equivalent to map markers and uses the same selection state.
- Fit the route without hiding important geometry behind the details card or bottom navigation.
